A neuron is a weighted vote

You’ll build the single unit that every neural network is made of, tune one by hand, and find the one problem it can’t solve alone.

A decision you already make

Saturday morning: park or not? Three things go into it, each a yes (1) or no (0):

  • $x_1$: is it sunny?
  • $x_2$: is it raining?
  • $x_3$: does someone have a cold?

They don’t count equally. Sun pulls you out a bit, rain keeps you in a lot, and a cold matters somewhat. Give each a number for how hard it pushes, and a minus sign when it pushes against:

$$z = 2x_1 - 4x_2 - 1.5x_3 + 0.5$$

Go if $z$ comes out above 0. The final $+0.5$ is your mood on a blank day: with all three inputs at 0, you’d mildly lean towards going.

Sunny, dry, someone has a cold: $z = 2(1) - 4(0) - 1.5(1) + 0.5 = 2 - 0 - 1.5 + 0.5 = 1$. Above 0, so you go.

That’s a neuron

An artificial neuron does exactly this. It takes some numbers in, multiplies each by its own weight, adds them up, and adds one more number, the bias:

$$z = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$$

  • A big positive weight: this input strongly argues “yes”.
  • A negative weight: this input argues “no”.
  • A weight near 0: this input is ignored.
  • The bias: how easily the neuron says yes when the inputs are quiet. It moves the threshold.

Then it passes $z$ through a fixed function to get its output. More on that function in a moment.

Inputs don’t have to be 0 or 1. They can be pixel brightnesses, or the outputs of other neurons. In GPT-3, a neuron in the first layer of each block reads 12,288 numbers at once.

A neuron has weights $2$, $-3$, $0.5$ and bias $-1$. Its inputs are $1$, $0$, $1$. What is $z$?

Multiply each input by its weight: $2 \times 1 = 2$, $\;-3 \times 0 = 0$, $\;0.5 \times 1 = 0.5$.

Add them: $2 + 0 + 0.5 = 2.5$.

Add the bias: $2.5 + (-1) = 1.5$.

You raise a neuron’s bias from $-1$ to $+2$ and leave the weights alone. What changes?

The bias is added every time, whatever the inputs are, so it shifts $z$ up by 3 for every input. Inputs that used to land just below 0 now land above it. The weights, which set how much each input counts, haven’t moved.

Try AND (yes only when both inputs are 1), then OR (yes when either is). Hint for AND: make both weights 1 and find a bias so that one input alone isn’t enough. Then try XOR: yes when exactly one input is 1.

With $w_1 = w_2 = 1$, which bias makes the neuron compute AND?

Check all four inputs with $b = -1.5$:

$(0,0)$: $0 + 0 - 1.5 = -1.5$, no. $(1,0)$ and $(0,1)$: $1 - 1.5 = -0.5$, no. $(1,1)$: $2 - 1.5 = 0.5$, yes.

$b = -0.5$ gives OR instead: one input alone reaches $1 - 0.5 = 0.5$. Same weights, different bias, different rule.

Why can no setting of the sliders solve XOR?

The yes dots are $(1,0)$ and $(0,1)$, the no dots $(0,0)$ and $(1,1)$: diagonal pairs. Any straight line that has both yes corners on its yes side also takes in at least one no corner. A single neuron can only draw one straight line, however big its weights. Lesson 2 fixes this with a second layer.

The squashing function

So far the neuron outputs a hard yes or no: 1 if $z > 0$, else 0. That’s a step. Real networks replace it with a smoother activation function, for a reason you’ll meet in Lesson 3: training works by nudging weights a little and seeing whether things improve, and a step gives no signal for small nudges. It’s flat everywhere except at the jump.

Two activations to know:

  • Sigmoid: $\sigma(z) = \dfrac{1}{1 + e^{-z}}$. A smooth step from 0 to 1, with $\sigma(0) = 0.5$. Reads as a probability.
  • ReLU (“rectified linear unit”): $\text{ReLU}(z) = \max(0, z)$. Negative becomes 0; positive passes through unchanged. Crude, cheap, and the workhorse of modern networks, along with smooth cousins of it.

A ReLU neuron computes $z = -1.5$. What does it output?

$\text{ReLU}(-1.5) = \max(0, -1.5) = 0$. A ReLU neuron with negative $z$ is silent: it outputs 0, whatever the size of the negative number.

You’ve met sigmoid before

Lesson 4 of the prediction topic turned logits into probabilities with softmax. Take softmax over just two options, with logits $z$ and $0$:

$$p = \frac{e^{z}}{e^{z} + e^{0}} = \frac{e^{z}}{e^{z} + 1}$$

Divide top and bottom by $e^{z}$. On top, $e^{z} \div e^{z} = 1$. On the bottom, $e^{z} \div e^{z} = 1$ and $1 \div e^{z} = e^{-z}$:

$$p = \frac{1}{1 + e^{-z}} = \sigma(z)$$

So a sigmoid neuron is a two-way softmax: “yes” has logit $z$, “no” has logit 0.

A sigmoid neuron has $z = 1$. What’s its output? (Use $e^{-1} \approx 0.368$.)

$\sigma(1) = \dfrac{1}{1 + e^{-1}} = \dfrac{1}{1 + 0.368} = \dfrac{1}{1.368}$.

$1 \div 1.368 \approx 0.731$.

Check with the softmax view: logits $1$ and $0$ give $2.718 \div (2.718 + 1) = 2.718 \div 3.718 \approx 0.731$.

Parameters

The weights and the bias are the neuron’s parameters: the numbers that training adjusts. Everything else (the inputs, the choice of ReLU) is either data or fixed design.

A neuron with $n$ inputs has $n$ weights and 1 bias, so $n + 1$ parameters. A layer of neurons that all read the same inputs needs that many per neuron:

WhatCount
One neuron, 3 inputs$3 + 1 = 4$
5 neurons, each reading the same 3 inputs$5 \times 4 = 20$
GPT-3, the whole modelabout 175 billion

When you hear “a 70B model”, that’s 70 billion of these knobs. Each is just a weight or a bias like the ones you set with the sliders above. None was set by hand.

A neuron is a weighted sum plus a bias, passed through a simple function. Its weights and bias are its parameters. One neuron can only draw one straight line through its inputs.

A tiny digit-reader looks at a 28 × 28 image, so 784 pixel inputs. Its single layer has 10 neurons (one per digit), each reading all 784 pixels. How many parameters?

Per neuron: 784 weights + 1 bias = 785.

Ten neurons: $10 \times 785 = 7850$.

Check

A neuron has a weight of $-5$ on input $x_2$. What does that tell you?

Each unit of $x_2$ subtracts 5 from $z$. The sign of the weight says which way the input votes; its size says how loudly. A weight near 0 would mean “ignored”.

A ReLU neuron has weights $1$ and $1$ and bias $-1$. Input $(0.3, 0.4)$. Output?

$z = 1(0.3) + 1(0.4) - 1 = 0.7 - 1 = -0.3$.

$\text{ReLU}(-0.3) = 0$.

What does “training” change in a neural network?

Training adjusts the parameters so the outputs match the data better. The inputs are the data. The activation function and the number of layers and neurons are fixed when the network is designed.

In your own words: what does one neuron compute, and why can’t one neuron do XOR?

It multiplies each input by a weight, adds them up with a bias to get $z$, and passes $z$ through an activation (step, sigmoid, ReLU). The boundary between yes and no is where $z = 0$, which is a straight line. XOR’s yes cases are diagonally opposite corners, and no single straight line separates them from the other two.
