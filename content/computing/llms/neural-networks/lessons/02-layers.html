Layers

You’ll beat XOR with a second layer, build a curve out of straight pieces, and see why stacking layers beats making one layer wider.

Neurons feeding neurons

Lesson 1 ended stuck: one neuron draws one straight line, and XOR needs more. The fix is to let neurons read the outputs of other neurons.

A layer is a group of neurons that all read the same inputs. Stack them: the first layer reads the data, the next reads the first layer’s outputs, and so on. The layers in between input and output are called hidden layers, because you never see their values directly. A stack like this is a multi-layer perceptron, or MLP.

XOR with two hidden ReLU neurons and one output:

  • $h_1 = \text{ReLU}(x_1 + x_2)$, which counts how many inputs are on
  • $h_2 = \text{ReLU}(x_1 + x_2 - 1)$, which only fires when both are on
  • $\text{out} = h_1 - 2h_2$
$x_1, x_2$$h_1$$h_2$$h_1 - 2h_2$
0, 0$\text{ReLU}(0) = 0$$\text{ReLU}(-1) = 0$$0 - 0 = 0$
1, 0$\text{ReLU}(1) = 1$$\text{ReLU}(0) = 0$$1 - 0 = 1$
0, 1$1$$0$$1$

The hidden layer turned the inputs into two new features, “how many” and “both”, and in those terms XOR is simple: count, minus a penalty for both.

Finish the table: what does the network output for $x_1 = 1$, $x_2 = 1$?

$h_1 = \text{ReLU}(1 + 1) = \text{ReLU}(2) = 2$.

$h_2 = \text{ReLU}(1 + 1 - 1) = \text{ReLU}(1) = 1$.

$\text{out} = 2 - 2 \times 1 = 0$. Both on gives no, so it’s XOR.

Why the squashing function is essential

Suppose you left out ReLU and just stacked weighted sums. Layer 1: $y = 2x + 1$. Layer 2: $\text{out} = 3y - 4$. Substitute:

$$\text{out} = 3(2x + 1) - 4 = 6x + 3 - 4 = 6x - 1$$

Two layers, and the result is one weighted sum plus a bias, which a single neuron could do. That always happens: a weighted sum of weighted sums is a weighted sum. Without a nonlinearity between them, a hundred layers collapse to one and you’re back to drawing a single straight line.

ReLU breaks the collapse. It’s the bend between layers that lets the next layer do something new.

Layer 1 computes $y = 4x - 2$ and layer 2 computes $\text{out} = 0.5y + 3$, with no activation in between. Which single neuron does the same job?

Substitute $y$: $\text{out} = 0.5(4x - 2) + 3$.

Expand: $0.5 \times 4x = 2x$ and $0.5 \times (-2) = -1$, so $\text{out} = 2x - 1 + 3 = 2x + 2$.

Two layers, one straight line. That’s why every real network puts an activation between layers.

Curves from bends

One input $x$, one output. A hidden ReLU neuron $\text{ReLU}(x - c)$ is flat until $x = c$, then rises with slope 1: a single bend at $c$. The output neuron adds several of these up, each times its own weight $a$. Adding bends gives a curve made of straight pieces.

Hint: the hill’s slope is 0, then $+1$ from $x = -1$, then $-1$ from $x = 0$, then 0 again from $x = 1$. At each bend, $a$ is how much the slope changes.

Which weights build the hill $\text{ReLU}(x+1) + a_2\,\text{ReLU}(x) + a_3\,\text{ReLU}(x-1)$?

Track the slope from left to right. Before $-1$: 0. After the first bend: $0 + 1 = 1$.

At $x = 0$ the slope must go from $+1$ to $-1$, a change of $-2$, so $a_2 = -2$.

At $x = 1$ it must go from $-1$ back to $0$, a change of $+1$, so $a_3 = 1$.

Same $1, -2$ pattern as the XOR network: a count, minus twice a later count.

Wide or deep?

With enough hidden neurons in a single layer you can put a bend anywhere and match any reasonable curve as closely as you like. That’s a theorem (the universal approximation theorem, 1989). So why do real networks have many layers?

Because a wide layer pays per bend. Each extra neuron adds roughly one more bend. Stacking layers multiplies instead. Take a two-neuron layer that makes a tent on $[0, 1]$:

$$T(x) = 2\,\text{ReLU}(x) - 4\,\text{ReLU}(x - 0.5)$$

Check: $T(0) = 0$. $T(0.5) = 2(0.5) - 0 = 1$. $T(1) = 2(1) - 4(0.5) = 2 - 2 = 0$. Up and back down.

Now feed the tent’s output into another copy of the same layer. As $x$ goes from 0 to 1, $T(x)$ sweeps 0→1 and back 1→0, so the second tent gets run through twice: two peaks. A third layer runs over each of those twice: four peaks.

Depth doubles the peaks with every layer; width only adds. With 10 layers of 2 neurons you get 512 peaks, which would take about 1,000 neurons in one layer. Real data isn’t a neat zigzag, but it is full of patterns built from patterns. In an image network, early layers pick out edges, later ones combine edges into shapes, later still shapes into objects. Each layer builds on the features the previous one found, the way “how many” and “both” made XOR easy.

Layers let neurons build features out of features. The activation between layers is what stops them collapsing into one. Depth multiplies what a network can express; width only adds.

How many peaks does the tent layer give when stacked 6 deep?

Each layer doubles the peaks: 1 layer gives 1 peak, so $k$ layers give $2^{k-1}$.

$k = 6$: $2^{5} = 32$ peaks, from just 12 neurons.

Counting parameters in a stack

Between two layers, every neuron in the second reads every output of the first. So a layer that reads $m$ numbers and has $n$ neurons has $m \times n$ weights plus $n$ biases.

This is exactly what sits inside every transformer block (the attention topic will show you the rest of the block). In GPT-3 each block’s MLP takes the 12,288 numbers that represent a token, widens them to a hidden layer 4 times as big, $4 \times 12{,}288 = 49{,}152$ neurons, applies the activation, and narrows back to 12,288:

$$12{,}288 \times 49{,}152 \approx 604 \text{ million weights in, and the same out}$$

So about 1.2 billion parameters per block. With 96 blocks, that’s about 116 billion of GPT-3’s 175 billion: two-thirds of the model is these plain layers.

A digit-reader has 784 pixel inputs, a hidden layer of 100 neurons and an output layer of 10. How many parameters in total?

Hidden layer: $784 \times 100 = 78{,}400$ weights, plus 100 biases: $78{,}500$.

Output layer: it reads the 100 hidden outputs, so $100 \times 10 = 1{,}000$ weights, plus 10 biases: $1{,}010$.

Total: $78{,}500 + 1{,}010 = 79{,}510$. Ten times Lesson 1’s single-layer version, and it can learn features the single layer can’t.

Check

Someone builds a 50-layer network but forgets the activation functions. What can it compute?

Without a nonlinearity, each layer is a weighted sum plus a bias, and substituting one into the next just gives another weighted sum plus a bias. All 50 collapse into one.

In the XOR network, what did the two hidden neurons $h_1$ and $h_2$ detect?

$h_1 = \text{ReLU}(x_1 + x_2)$ is the count. $h_2 = \text{ReLU}(x_1 + x_2 - 1)$ is 1 only when both are on. The output combines them: count minus twice “both”. Neither hidden neuron computes XOR (“exactly one”) by itself, because a single neuron can’t, as Lesson 1 showed. XOR only appears at the output.

A model has 96 blocks, each with an MLP of about 1.2 billion parameters. Roughly how many billion parameters are in MLPs?

$96 \times 1.2 = 115.2$, or about 116 billion using the unrounded 1.208 billion per block. That’s GPT-3: about two-thirds of its 175 billion parameters.

In your own words: why do networks use many layers rather than one very wide one?

One wide layer can in principle match any curve, but it pays for each bend with a neuron. Each extra layer builds on the features the previous layer found, so complexity multiplies: the tent stack doubles its peaks per layer. Real data is made of patterns built from patterns (edges, shapes, objects), which is what depth is good at.
