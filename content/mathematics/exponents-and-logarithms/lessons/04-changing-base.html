Changing base

$\log_2$, $\log_{10}$ and $\ln$ ask the same question with a different-sized step. Converting between them is a single multiplication.

Warm-up

One more lap of the rules, because the new formula today looks a lot like one of the traps.

What is $\log_2 80 - \log_2 10$?

Subtracting logs means the numbers were divided: $\log_2 \tfrac{80}{10} = \log_2 8 = 3$.

$\log_2 70$ keeps the minus, and $\log_2 80 \div \log_2 10$ divides the logs. Remember that second shape. It comes back later in this lesson, and there it means something different.

Same question, different ruler

$\log_2 x$ asks “2 to what power makes $x$?” Swap the 2 for any positive number (other than 1) and you get a log in that base. Base 10 asks “10 to what power makes $x$?”

  • $\log_{10} 1000 = 3$, because $10^3 = 1000$.
  • $\log_{10} 1 = 0$, because $10^0 = 1$.
  • $\log_{10} 0.1 = -1$, because $10^{-1} = \tfrac1{10}$.

Where $\log_2$ counts doublings, $\log_{10}$ counts tenfolds, which is roughly counting digits. A 4-digit number like 5,000 sits between $10^3$ and $10^4$, so its $\log_{10}$ is between 3 and 4. The button marked log on a calculator is $\log_{10}$.

What is $\log_{10} 0.01$?

$0.01 = \tfrac1{100} = \tfrac1{10^2} = 10^{-2}$. So $\log_{10} 0.01 = -2$: two tenfolds down from 1.

One curve, three heights

Here are three bases on the same axes: $\log_2$, $\log_{10}$, and $\ln$ (base $e \approx 2.718$; Lesson 5 explains where $e$ comes from). Move $x$ and watch the ratios at the bottom.

log₂ x ln x log₁₀ x log₂ x ÷ log₁₀ x log₂ x ÷ ln x

The ratios never change (except at $x = 1$, where every log is 0). The three curves have the same shape, just stretched to different heights. $\log_2 x$ is always about 3.32 times $\log_{10} x$.

Here’s why. You know from Lesson 3 that $10 \approx 2^{3.32}$: one tenfold is 3.32 doublings. Say $\log_{10} x = y$. Then:

  1. $x = 10^y$
  2. $= (2^{3.32})^y$ (replace 10 with $2^{3.32}$)
  3. $= 2^{3.32\,y}$ (a power of a power multiplies the exponents)
  4. So $\log_2 x = 3.32\,y = 3.32 \times \log_{10} x$.

Counting in tenfolds or in doublings is like measuring in feet or in inches: same length, different unit, and one fixed number converts between them.

$\log_{10} 100 = 2$. Using $\log_2 10 \approx 3.32$, what is $\log_2 100$? (Two decimal places.)

Multiply by the conversion factor: $\log_2 100 = 3.32 \times \log_{10} 100 = 3.32 \times 2 = 6.64$.

Sanity check from Lesson 3: $64 < 100 < 128$, so it should be between 6 and 7. It is.

The change-of-base formula

The same argument works for any two bases. Say you want $\log_b x$ but your calculator only does some other base $a$. Call the answer $y$:

  1. $y = \log_b x$ means $b^y = x$.
  2. Take $\log_a$ of both sides: $\log_a(b^y) = \log_a x$.
  3. Power rule on the left: $y \times \log_a b = \log_a x$.
  4. Divide both sides by $\log_a b$: $y = \dfrac{\log_a x}{\log_a b}$.

$$\log_b x = \frac{\log_a x}{\log_a b}$$

So to get $\log_2 27$ on a calculator that only has log and ln:

$$\log_2 27 = \frac{\log_{10} 27}{\log_{10} 2} = \frac{1.4314}{0.3010} \approx 4.755$$

That’s the same 4.75 you found with the slider in Lesson 3. Using $\ln$ instead gives $\tfrac{3.2958}{0.6931} \approx 4.755$ too. The base on top and bottom just has to match.

Dividing two logs is not the log of a division: $\dfrac{\log x}{\log b} \ne \log \dfrac{x}{b}$. A log divided by a log does one job only: it changes base. The bottom, $\log_a b$, is the size of one step of the new base, measured in the old one.

Which of these equals $\log_5 20$?

Change of base with $a = e$: $\log_5 20 = \tfrac{\ln 20}{\ln 5} \approx \tfrac{2.996}{1.609} \approx 1.86$. Check: $5^{1.86}$ is a bit under $5^2 = 25$, and 20 is a bit under 25. ✓

$\ln \tfrac{20}{5}$ and $\ln 20 - \ln 5$ are the same number, $\ln 4 \approx 1.39$, which is the quotient rule, not a base change. $\tfrac{\ln 5}{\ln 20}$ is upside down: it gives $\log_{20} 5$.

Using base 2 for the logs, what is $\log_4 32$?

$\log_4 32 = \dfrac{\log_2 32}{\log_2 4} = \dfrac{5}{2} = 2.5$.

Check: $4^{2.5} = 4^2 \times 4^{0.5} = 16 \times 2 = 32$. ✓ Each step of 4 is two doublings, so five doublings make two and a half fourfolds.

Bits and nats

Machine-learning code measures surprise with $\ln$, not $\log_2$. Surprise $-\ln p$ comes out in nats instead of bits. It’s the same quantity in a different unit, and change of base gives the exchange rate:

$$\log_2 x = \frac{\ln x}{\ln 2} \approx \frac{\ln x}{0.693} \approx 1.443 \times \ln x$$

nats → bits× 1.443
bits → nats× 0.693

A nat is the bigger unit (about 1.44 bits), because $e \approx 2.718$ is a bigger step than 2. So the same surprise is a smaller number of nats than of bits. Worked through:

  1. A fair coin landing heads: $-\log_2 \tfrac12 = 1$ bit.
  2. In nats: $-\ln \tfrac12 = \ln 2 \approx 0.693$ nats.
  3. A training run reports a loss of 2.0 (nats per token). In bits: $2.0 \times 1.443 \approx 2.89$ bits per token.

A training loss is 3.0 nats per token. How many bits per token is that? (Two decimal places.)

Nats to bits: multiply by $\tfrac1{\ln 2} \approx 1.443$. So $3.0 \times 1.443 = 4.329 \approx 4.33$ bits per token.

Check

Your calculator says $\log 50 = 1.699$ and $\log 2 = 0.301$ (base 10). What is $\log_2 50$? (Two decimal places.)

Change of base: $\log_2 50 = \dfrac{\log 50}{\log 2} = \dfrac{1.699}{0.301} \approx 5.64$.

Sanity check: $32 < 50 < 64$, so it’s between 5 and 6. ✓

An event has probability $\tfrac18$. That’s 3 bits of surprise. How many nats? (Use $\ln 2 \approx 0.693$; two decimal places.)

Bits to nats: multiply by $\ln 2$. $3 \times 0.693 = 2.079 \approx 2.08$ nats.

Directly: $-\ln \tfrac18 = \ln 8 = \ln(2^3) = 3 \ln 2$, the power rule again.

Which is bigger: one bit or one nat?

One nat ≈ 1.443 bits. A nat is one $e$-fold (×2.718) and a bit is one doubling (×2), and multiplying by 2.718 is the bigger step. That’s why the same loss is a smaller number in nats than in bits.

In your own words: why is $\log_2 x \div \log_{10} x$ the same number (about 3.32) for every $x$?

Because $10 = 2^{3.32}$: every tenfold is exactly 3.32 doublings. Counting how many tenfolds make $x$ and counting how many doublings make $x$ measure the same distance in different units, so one is always 3.32 times the other, like inches and feet.
